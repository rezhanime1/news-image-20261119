A front-page image of the day in world news — 19 November 2026 — built for the [make.fun news-image-20261119 bounty](https://make.fun/bounty/news-image-20261119).

`main.py` copies the rendered front page (`news.png`, 1024×1024) to the output path. The image is rendered offline and shipped with this repository; the program is deterministic and uses only the standard library.
